The Google Play version is a separate app, signed with Google's key, so it installs beside the open-source build rather than over it. Android refuses an update signed with a different key, so never install a build with another certificate over an existing install.

Check an APK

apksigner verify --print-certs switchboard-vYYYY.MM.P.apk
sha256sum -c switchboard-vYYYY.MM.P.apk.sha256

Check where it was built (strongest)

Every release APK carries a build-provenance attestation signed by GitHub Actions. A pass proves the exact bytes you downloaded came from this repository's release workflow.

gh attestation verify switchboard-vYYYY.MM.P.apk \
  --repo garfiec/Librechat-Mobile \
  --signer-workflow garfiec/Librechat-Mobile/.github/workflows/release.yml

iPhone and iPad

The TestFlight beta comes from Apple, signed by Apple, so there's nothing to check. The .ipa on GitHub Releases is for sideloading tools, which sign it with your own certificate. Its .sha256 file confirms the download is complete. Most IPAs also carry a build attestation you can check the same way as the APK's, but unlike the APK's it isn't guaranteed for every release.

shasum -a 256 -c switchboard-vYYYY.MM.P.ipa.sha256
