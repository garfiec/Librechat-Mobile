Compatibility

Which LibreChat versions work?

Each app release is tested against a range of LibreChat server versions. Newer servers work on a best-effort basis until the next update.

See the tested versions in each release's notes on GitHub Releases.

Not sure what your server runs?

Once you're signed in, the app shows it under Settings → About, next to the app's own version, and shows a notice after you sign in if your server runs a different LibreChat release than the one this app version was built for. You can dismiss it for that server version. Before you install, ask whoever runs your server.
